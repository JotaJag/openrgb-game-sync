# Herramientas históricas: no ejecutar como instalador

Estos scripts documentan despliegues y restauraciones de la máquina original.
Contienen rutas específicas y se han archivado sin adaptar su funcionamiento.
El instalador para terceros es `install.sh` del paquete de release; la
desinstalación es `uninstall.sh`. Consulta `docs/INSTALL.md` desde la raíz.
