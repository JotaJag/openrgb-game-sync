Prototipo para Linux x86_64 con OpenRGB 1.0 / Qt6 / API 5.

Extrae el paquete, cierra OpenRGB y ejecuta `python3 install.py` sin sudo.
Consulta `INSTALL.md` para configurar el prefijo Wine/Proton y desinstalar.

Incluye Game Sync, Effects con prioridad compartida y el servicio de protocolo
10 para la DLL Corsair original. No incluye DLL de juegos. La instalación deja
pausada la preparación automática y no modifica juegos ni launchers.

Instalación y restauración comprobadas en carpetas temporales. Diablo IV fue
validado por el usuario con la integración original. El paquete de instalación
aún requiere validación en otra máquina compatible. No es un binario universal
para todas las distribuciones ni una versión Windows, macOS o Flatpak.
